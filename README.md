# BJ-MapEdit

## 🎮 Mod Introduction

This mod provides map creators with a comprehensive suite of visual editors, covering common datapack features such as items, books, entities, villagers, recipes, advancements, datapacks, and game rules. Tasks that originally required manually writing JSON files and repeatedly checking commands can now be completed directly in-game through graphical interfaces, significantly lowering the entry barrier for new creators. All editors support saving and reusing templates, facilitating batch production and team collaboration.

## 😋 Mod Features

### 📦 Item Editor
- Edit item name, lore, max stack size, max durability, and custom model data.
- Visually configure enchantments, attributes, and placeable blocks.
- One-click hide enchantments / attributes / unbreakable / other miscellaneous tooltips.
- Select items directly from your inventory to generate and copy the `/give` command.

### 📖 Book Editor
- Edit book title, author, and page content, with support for adding/removing multiple pages and page-turning navigation.
- Rich text formatting: 16 colors, bold / italic / underline / strikethrough / glowing text, and custom hex colors.
- Supports clearing formatting, copying as JSON, and saving as a book template.

### 🖼 Item Frame / Armor Stand Editor
- Item Frame: Set displayed item, glowing, invisible frame, and rotation angle.
- Armor Stand: Adjust pose and orientation.
- One-click generate summon commands, with template saving support.

### 🧍 Entity Editor
- After selecting an entity, visually edit NBT data and custom data.
- Provides an entity preview, which can be saved as an entity template for reuse.

### 🧑‍🌾 Villager Editor
- Set profession, villager type, and level.
- Visually edit the trade table: buy item, second buy item, sell item, and trade count, with real-time preview of trade results.
- Supports villager templates.

### 🍳 Recipe Editor
- Visually edit shaped and shapeless recipes.
- Category management (Building / Redstone / Equipment / Miscellaneous) and recipe groups.
- Supports survival-only recipes, with one-click export to datapacks.

### 🏆 Advancement Editor
- Select triggers (17 types), set icon / background / parent advancement.
- Advancement frame style: Task / Goal / Challenge.
- Visual configuration of conditions: biomes, dimensions, items, entities, blocks, recipes, and experience points.
- Display control: chat broadcast, toast notification, or hidden.

### 🗂 Datapack Editor
- Create new datapacks, files, and folders directly in-game.
- Browse datapack file lists and copy JSON content.
- Name validity verification and file size limit protection.

### ⚙️ Game Rule Editor
- Visual toggles for all game rules, no need to memorize rule names.
- One-click apply, restore defaults, and save as rule templates.

### 🧰 General Features
- Every editor has a built-in template system: Save / Apply / Rename / Delete / New Folder / Drag to organize.
- Support for Chinese input method cursor positioning and automatic command suggestion pop-ups.
- Admin permission verification to prevent unauthorized players from misoperation.
- Unified themed off-white input boxes for a consistent global UI style.

## 🎮 Controls

Press the numpad keys **1 ~ 9** to open the corresponding editor.
