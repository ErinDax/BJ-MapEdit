# ✨我有：
这个模组为游戏增加了9个编辑器：
·项目编辑器
·图书编辑
·游戏规则编辑器
·实体编辑器
·展示框架 / 盔甲支架编辑器
·村民编辑器，数据包编辑器
·食谱编辑器
·进展编辑器
该网站旨在协助地图创作者开发地图。通过可视化某些数据包功能，它使新手数据包创建者更容易开始。
# 🎮控制
按数字键盘1到数字键盘9即可打开相应的编辑器。
